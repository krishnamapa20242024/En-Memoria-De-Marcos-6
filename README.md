# Memorial: Marcos Rodriguez (Proyecto web estática RA2)

7 páginas: index, historia, familia, pasiones, galeria, videos y recuerdos.
Tecnologías: HTML semántico, Tailwind CSS (CDN) y Alpine.js (CDN). Fotos en `img` y videos en `video`.
Interactividad: menú móvil, acordeón, pestañas, modal, galería con foto ampliada, carrusel y formulario de mensajes.

## Publicar
1. Sube la carpeta completa a GitHub o GitLab.
2. Publícala con GitHub Pages, Netlify o Vercel (`index.html` en la raíz).
